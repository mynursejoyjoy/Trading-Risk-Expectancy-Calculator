  3. 複製 API Key：登入後進入 https://finnhub.io/dashboard ，頁面最上方就會顯示你的 API Key，直接點擊複製。

二、凱利公式 (Kelly Criterion)

核心原理：由 John L. Kelly Jr. 提出，用於在已知「勝率 (W)」與「盈虧比 (R)」的前提下，計算每筆交易應承受多少總資金風險，才能讓長期複利增長最大化，同時避免過度下注導致爆倉。

凱利比例 = 勝率 - (敗率 ÷ 盈虧比)

使用方法：若計算結果小於或等於 0%，代表策略不具正期望值，不應開倉。實戰中「全凱利」的資金波動非常劇烈，建議將顯示的凱利比例除以 2（半凱利）或除以 4（四分之一凱利）作為單筆最大風險上限。

三、蒙地卡羅模擬 (Monte Carlo Simulation)

核心原理：即使策略長期具有正期望值，短期內的輸贏順序也是隨機的（例如可能連續止蝕 5 次，也可能連續獲利）。蒙地卡羅模擬透過大量隨機抽樣，重現真實交易中資金曲線的起伏與回撤風險。

使用方法：本計算機會依你設定的勝率與盈虧比進行多組隨機交易序列模擬，並於圖表顯示位於中位數的代表路徑，與藍色的「理論期望值曲線」對比。建議多按幾次「重新抽樣模擬」，觀察模擬期間的最大回撤與最長連虧次數，確保你的單筆止蝕比例在心理與資金承受範圍內。
